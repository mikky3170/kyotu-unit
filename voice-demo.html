📖 VoiceSuite Studio システム説明ガイド ＆ 操作マニュアル

🎯 1. 本ツールの目的・狙い

本システムは、「実用性の極めて高い音声入力」 と 「長文でも途切れない高品質な音声読み上げ」 を1つの画面に統合し、かつ業務システムや別アプリケーションへパーツ単位でそのまま移植・再利用できるように設計された共通音声入出力基盤です。

🎙️ 音声入力の革新アプローチ

従来の音声認識は「息継ぎで前の文章が消える」「改行のない巨大な文章の塊になる」課題がありました。本ツールでは前の文章を消さずに累積保持し、カーソル位置へのインライン挿入とGeminiによる2種類の整形スタイルを提供します。

🔊 音声読み上げの革新アプローチ

高品質音声合成の「長文で待たされる」「多音字の誤読が多い」課題を解決。先読み逐次再生（スタートバッファリング）により待たずに即時再生を開始。原稿の英字や漢字は100%維持したまま、5大文法カテゴリー自律判定で発音のみを完璧に最適化します。

⚖️ 2. 音声入力 整形モードの違い（パターンA vs パターンB）

話者の用途に合わせて、Geminiが文章の整形スタイルを劇的に切り替えます。

【A】原文忠実モード（推奨） 口調・熱量保持

話者の選んだ語彙・語尾（「〜だと思う」「〜なんですけどね」等）を1文字も変えずに100%保持します。単なる言い淀みフィラー（えーと、あの等）のみを削除し、接続詞で単一改行を入れて読みやすくします。

▼ 変換イメージ
「明日のミーティングなんですけれども、ちょっと準備が遅れてまして、時間を1時間ズラせますでしょうか。」
【B】AI Studioスマートモード 複文分割・重複排除

話した内容は100%保持したまま、「〜ですが、〜だったので、〜ですけど」と長く続く文を適切な「。」で分割。同じ意味の堂々巡りや重複を整理し、ビジネスチャットやドキュメントにそのまま使える洗練された文章へ昇華します。

▼ 変換イメージ
「明日のミーティングについてご相談です。資料準備に遅れが生じるため、開始時間を1時間遅らせていただくことは可能でしょうか。」

🚀 4. 操作手順・簡易マニュアル

1
初期設定（初回のみ）

右上の ⚙️ 設定 を開き、Gemini API Key を登録します。ローカルVOICEVOXを利用する場合は「🔍 接続テスト」を押して接続成功を確認し、「保存して閉じる」をクリックします。

2
右ペインで音声を入力する

【A】原文忠実 または 【B】AI Studioスマート を選び、🎙️ マイクボタン を押して発話します。もう一度押すと停止し、約1〜2秒で綺麗にAI整形されます。言い忘れた言葉はカーソルを置いて追加発話できます。

3
左ペインで読み上げ・評価を行う

「⬅️ 読み上げエリアにコピー」 を押して原稿を転送し、話者と話速を選んで 「▶️ 読み上げ開始」 をクリックします。画面の英字・漢字表記を崩さず、正しい発音でモニターが黄色く発光しながらスムーズに朗読されます。

⚙️ モジュール接続・環境設定

gemini-3.5-flash-lite / gemini-flash-lite-latest を呼び出して高精度AI整形と自律型多音字文脈判定を行います。
Windowsやブラウザ環境での安定通信のため、http://127.0.0.1:50021 を推奨します。
ローカル版の標準VOICEVOXでは空欄で動作します。認証付きプロキシやAPI連携時に設定してください。
独自の専門用語や固有名詞を登録できます。一般的な日本語や多音字はAIが文脈から自動判別します。
