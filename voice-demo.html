📖 VoiceSuite Studio システム説明ガイド ＆ 操作マニュアル

🎯 1. 本ツールの目的・狙い

本システムは、「実用性の極めて高い音声入力」 と 「長文でも途切れない高品質な音声読み上げ」 を1つの画面に統合し、かつ業務システムや別アプリケーションへパーツ単位でそのまま移植・再利用できるように設計された共通音声入出力基盤です。

🎙️ 音声入力の革新アプローチ

従来の音声認識は「息継ぎで前の文章が消える」「改行のない巨大な文章の塊になる」課題がありました。本ツールでは前の文章を消さずに累積保持し、カーソル位置へのインライン挿入とGeminiによる8s-16s-30sの段階的リトライ整形を提供します。

🔊 音声読み上げの革新アプローチ

高品質音声合成の「長文で待たされる」「多音字の誤読が多い」課題を解決。先読み逐次再生（スタートバッファリング）により待たずに即時再生を開始。PCローカル合成に加え、未起動時も安心なクラウド合成（tts.quest）へのシームレス切替を搭載しています。

⚖️ 2. 音声入力 整形モードの違い（パターンA vs パターンB）

話者の用途に合わせて、Geminiが文章の整形スタイルを劇的に切り替えます。

【A】原文忠実モード（推奨） 口調・熱量保持

話者の選んだ語彙・語尾（「〜だと思う」「〜なんですけどね」等）を1文字も変えずに100%保持します。単なる言い淀みフィラー（えーと、あの等）のみを削除し、接続詞で単一改行を入れて読みやすくします。

▼ 変換イメージ
「明日のミーティングなんですけれども、ちょっと準備が遅れてまして、時間を1時間ズラせますでしょうか。」
【B】AI Studioスマートモード 複文分割・重複排除

話した内容は100%保持したまま、「〜ですが、〜だったので、〜ですけど」と長く続く文を適切な「。」で分割。同じ意味の堂々巡りや重複を整理し、ビジネスチャットやドキュメントにそのまま使える洗練された文章へ昇華します。

▼ 変換イメージ
「明日のミーティングについてご相談です。資料準備に遅れが生じるため、開始時間を1時間遅らせていただくことは可能でしょうか。」

🚀 4. 操作手順・簡易マニュアル

1
初期設定（初回のみ）

右上の ⚙️ 設定 を開き、Gemini API Key を登録します。合成エンジン（ローカル / クラウド）を選択し、「保存して閉じる」をクリックします。

2
右ペインで音声を入力する

【A】原文忠実 または 【B】AI Studioスマート を選び、🎙️ マイクボタン を押して発話します。もう一度押すと停止し、8s-16s-30sの段階的リトライで綺麗にAI整形されます。

3
左ペインで読み上げ・評価を行う

「⬅️ 読み上げエリアにコピー」 を押して原稿を転送し、話者と話速を選んで 「▶️ 読み上げ開始」 をクリックします。エラーや進行状況は読み上げエリア下のステータス枠に表示されます。

⚙️ モジュール接続・環境設定

gemini-3.5-flash-lite / gemini-flash-lite-latest を呼び出して高精度AI整形と自律型多音字文脈判定を行います。
PCでVOICEVOXアプリを立ち上げ忘れることが多い場合は「クラウド合成」を選択してください。
PCローカル環境では http://127.0.0.1:50021 を指定します。
クラウド合成 (api.tts.quest) の個別キーや外部サーバーのAPIキーを設定できます（空欄でも利用可能）。
長文の音声生成でタイムアウトする場合は 30000（30秒）などに設定してください（最低10秒保証）。
独自の専門用語を登録できます。JSON形式で保存して他の環境へ簡単に移行・共有できます。
